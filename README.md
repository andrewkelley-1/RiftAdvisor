## What It Does

Rift Advisor is an AI-powered coaching web application that provides personalized champion pick and item build recommendations for League of Legends players. The user inputs their Riot ID and current draft (ally and enemy champions by role), and the app returns a tailored recommendation with explanations — grounded in real account data and current patch item statistics.

**Data flow summary:**
1. User enters their Riot ID — the app fetches their rank, top champions, and last 10 match results from the Riot Games API
2. User selects ally and enemy champions by role using dropdowns
3. The prompt engineering layer in `prompt_builder.py` builds a dynamic system prompt combining the user profile, match history, and draft state
4. The vector store (Chroma + sentence-transformers) performs two semantic searches over the current patch item database — one for offensive items and one for defensive/situational items — and injects the results into the prompt
5. The full enriched prompt is sent to the LLM via Groq
6. The response is displayed in a structured chat UI — the user can follow up to refine recommendations

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/RiftAdvisor.git
cd RiftAdvisor
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure API keys

Create a `.env` file in the project root. **Never commit this file to the repository.**

```
GROQ_API_KEY=your_groq_api_key_here
RIOT_API_KEY=your_riot_api_key_here
```

- Get a free Groq API key at [console.groq.com](https://console.groq.com)
- Get a free Riot developer API key at [developer.riotgames.com](https://developer.riotgames.com)
- **Note:** Riot development API keys expire every 24 hours and must be regenerated each day

### 4. Fetch current patch data from Data Dragon

```bash
python backend/data_dragon.py
```

Downloads and caches current patch item and champion data locally. Re-run at the start of each new League of Legends patch.

### 5. Build the vector store

```bash
python backend/vector_store.py
```

Embeds all items using `all-MiniLM-L6-v2` and builds the Chroma vector database for semantic item retrieval. Downloads the embedding model (~80MB) on first run. Re-run after each patch alongside `data_dragon.py`.

### 6. Run the application

```bash
python -m streamlit run frontend/app.py
```

## How to Use

1. Enter your **Riot ID** (e.g. `PlayerName#NA1`) and click **Load Profile**
2. Your rank, role, and top 5 champions are auto-filled from your account
3. Select your **ally team** and **enemy team** by role using the dropdowns
4. Click **Start Session** — the coach automatically analyzes the draft and returns a recommendation
5. Ask follow-up questions in the chat input to refine the advice

## How It Works

### Prompt Engineering
Every session builds a dynamic system prompt in `prompts/prompt_builder.py` that combines the user's profile (rank, role, top champions), their recent match history, the full draft state (ally and enemy teams by role), and patch-accurate item data retrieved from the vector store. This gives the LLM rich, personalized context rather than relying on generic training data.

### RAG — Semantic Item Retrieval
Rather than hardcoding builds or relying on the LLM's training data, Rift Advisor uses a Chroma vector store to perform semantic similarity search over current patch item data. Two queries are made per session — one offensive and one defensive — based on the enemy composition. Items are embedded with strategic context (e.g. "buy Banshee's Veil against heavy AP crowd control") so retrieval is situation-aware rather than purely stat-based.

### Riot API Integration
On profile load, the app fetches the player's current ranked tier, most played champions by mastery points, and last 10 match results from the Riot Games API. This data is injected into the system prompt so the coach can tailor advice to the player's actual skill level and recent performance.

### Iterative Refinement
The full conversation history is maintained in `st.session_state` across turns and included in every API call, allowing the model to reference its previous recommendations and refine them based on follow-up questions.
